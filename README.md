# Tarbiyat — Topological Bildung

A first-principles metatheory of human capability, education, and development.
Twenty-two high-density posters tracing one continuous thread from embodied play to
architectural mastery — companion to *The Geometry of Becoming* (`zistgah/tabdili`).

**Live site:** the landing page loads directly from the repository root
(`index.html`), with a filterable poster **reader** and a browser-only conversation
**seeder**.

- `index.html` — landing page (book-cover hero, section overview, poster grid)
- `reader.html` — full-size, filterable poster gallery with deep links
- `seed.html` — client-side prompt composer (poster × role); no data leaves the page
- `assets/posters/` — the 22 posters
- `assets/metadata/tarbiyat-index.json` — canonical poster index (titles, sections, topics)
- `.github/ISSUE_TEMPLATE/` — chapter · simulation · critique · bug
- `metadata/misty.json` — canonical DOI metadata (transformed by misty)
